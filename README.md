# CalcuBit Ecommerce — Proyecto EBAC

Proyecto académico realizado con HTML semántico, metodología BEM, Sass, CSS responsive y JavaScript.

## Funcionalidades JavaScript
- Carrusel principal automático y manual.
- Carrito lateral con alta y eliminación de productos.
- Badge y total del carrito actualizados desde el DOM.
- Persistencia del carrito con LocalStorage.
- Filtrado por categorías.
- Búsqueda de productos.
- Menú lateral responsive.

## Estructura
- `index.html`
- `css/main.css`
- `scss/`
- `js/app.js`
- `assets/img/`


## Interacciones DOM añadidas

- `mouseenter` y `mouseleave` resaltan las tarjetas de producto al pasar el mouse.
- Las tarjetas de PlayStation, Xbox y Nintendo filtran el catálogo por plataforma.
